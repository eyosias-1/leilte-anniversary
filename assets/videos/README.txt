3. The website uses lazy loading (`preload="none"`) so it will never slow down your phone or download all videos at once.
4. When a video is started, any other playing video automatically pauses.
5. If a video hasn't been added yet, a cute romantic pink placeholder poster is displayed so the layout is always beautiful!
